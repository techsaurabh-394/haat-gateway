Marathi speakers often type grocery lists in Latin letters. Add common Marathi variants to `packs/ondc-ret10-grocery/lexicon.json`, for example *kanda* (onion), *batata* (potato), *sakhar* (sugar), *tandul* (rice), *gahu pith* (wheat flour), *dudh* (milk).

**Do:** add the variants to the right entries, and add one test line per word in `test/lexicon.test.ts`.
**Careful:** a variant can belong to only one product (`npm test` checks this).
**Done when:** `npm test` passes and `grocery.parse('2 kilo kanda aur 1 kilo batata')` returns onion and potato.
