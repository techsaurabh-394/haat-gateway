title: ops: reconcile operations interrupted mid-confirm
labels: help wanted
---
If the gateway crashes during a Beckn `confirm`, the operation stays `performing` and answers 503 forever (safe, never a double order, but stuck). See `src/poppy/operations.ts` and docs/limitations.md.

**Do:** store the Beckn `transaction_id` with the operation before confirming; add a reconciler that asks the seller (`status`) and marks the operation performed (with the order) or pending (nothing was ordered).
**Done when:** a test kills the gateway mid-confirm (use a slow mock seller), restarts it, and the same approval returns the order without a second confirm.
