Haat offers Direct Sign-In only. Device Sign-In (RFC 8628) suits agents that can't receive a browser redirect.

**Do:** read spec 4.3 and RFC 10027 section 2 first. Add `device_authorization_endpoint`, a `/device` page where the person enters the code, polling at the token endpoint with `interval` and `slow_down`, and list the grant in metadata.
**Done when:** tests cover approve, decline, expiry and polling too fast, and the official validator's device checks run (they are skipped today).
