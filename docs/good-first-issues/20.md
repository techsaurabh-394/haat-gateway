title: security: block public hostnames that resolve to private addresses
labels: security, help wanted
---
`src/poppy/url-policy.ts` blocks private IP literals but not hostnames that resolve to private IPs (DNS rebinding, internal names). See docs/security.md.

**Do:** resolve the hostname with `node:dns/promises` before fetching client metadata and JWKS (the 60-second failure cache in session.ts stays), reject private, loopback and link-local results (unless dev mode), and connect to the checked address so a second lookup can't change it.
**Done when:** tests use a stub resolver to show both the blocked and the allowed cases.
