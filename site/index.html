How it works

A bridge between two protocols.

Personal agents speak Poppy. Indian sellers speak Beckn. Haat translates, and owns the one decision that must not be automated: the purchase.

Understand

"2 kilo aata" or "இரண்டு கிலோ அரிசி" becomes wheat flour · 2000 g using a data-driven lexicon.

Search

Signed Beckn search fan-out to sellers from the ONDC registry. Pack sizes that waste least.

Ask

The gateway answers 403 approval_required with an exact summary. The human approves one revision.

Confirm once

Beckn confirm runs at most once, even across restarts. Unknown outcome means 503 Retry-After, never "failed".

Features

Built so small sellers don't become invisible.

Big consumer agents are adopting Poppy. Haat makes ONDC sellers reachable by every one of them, with the same safety.

🔐

Human approval gate

Operations extension v2. The person approves one exact revision. Orders and cancels both need a yes.

1️⃣

Exactly-once orders

Persisted across restarts. Retrying the same approval returns the same order, never a second one.

🗣️

11 Indian languages

Hindi, Bhojpuri, Marathi, Bengali, Tamil, Telugu, Gujarati, Kannada, Malayalam, Punjabi, Odia. Native script and Latin letters.

🧾

Beckn buyer app

Ed25519 + BLAKE2b-512 signing, signed ONDC v2 registry lookups, search, select, init, confirm, status, cancel.

✅

Poppy conformant

Official validator over real HTTPS: 99 checks passed, 0 failed, 0 warnings. Direct Sign-In with PKCE.

💬

Conversations and SSE

Events, cursors, long polling, server-sent events with Last-Event-ID, idempotent message IDs.

🛒

Smart baskets

Chooses pack sizes that waste least and the single seller covering most of your list. Says what is missing.

📦

Zero runtime deps

Node 22.18+ runs TypeScript directly. SQLite via node:sqlite. Tiny audit surface.

🧩

Domain packs

Grocery and food today. Add a vertical with two JSON files. Most contributions need no TypeScript.

Safety

The model never holds the keys.

The Company Agent is rule-based on purpose. No language model touches keys, session JWTs or the approval step.

  • 01Every request carries a signed Poppy-Session JWT: aud, htm, htu, iat, ath, replay-protected by jti.
  • 02URL fetching is HTTPS-only and refuses private addresses (SSRF).
  • 03Approval binds to one revision, one Session, and expires.
  • 04Every storage namespace has a cap. No unbounded growth.
