Why Haat

Agents can talk to sellers. They shouldn't spend without you.

Consumer AI agents speak Poppy. India's open commerce network speaks Beckn. Haat sits between them, translates every call, and owns the one decision that must never be automated: the purchase.

Understand how India types

A data-driven lexicon turns everyday requests in native scripts or Latin spellings into structured search terms and quantities.

"do kilo aata" → wheat flour · 2000 g

Bridge Poppy to Beckn

Signed Beckn search fans out to sellers from the ONDC registry, then builds the best single-seller basket with the least wasted pack size.

Poppy 0.3 → Beckn · Ed25519 signed

Stop at the gate

Orders and cancels return 403 approval_required with an exact summary. The person approves one revision. Confirm runs at most once.

How it works

Four steps from a sentence to a single, approved order.

01

Understand

"2 kilo aata" or "இரண்டு கிலோ அரிசி" becomes wheat flour · 2000 g.

02

Search

Signed Beckn search to registry sellers. Pick pack sizes that waste least.

03

Ask

Gateway returns an exact summary. The human approves one specific revision.

04

Confirm once

Persisted across restarts. Unknown outcome means 503 Retry-After, never a double order.

Platform

Everything the buyer side needs. Nothing it doesn't.

Built so small sellers don't become invisible as consumer agents adopt Poppy, with the same safety guarantees for every agent.

Human approval gate

Operations extension v2. Approval binds to one revision, one session, and expires. Orders and cancels both need a yes.

HTTP/1.1 403 Forbidden
"error": "approval_required",
"summary": "Kashi Kirana · ₹197 · COD"

Exactly-once orders

Idempotency is persisted in SQLite across restarts. Retrying the same approval returns the same order, never a second one.

retry #1 → 201 order KKS-1001
retry #2 → 201 order KKS-1001 (replayed)

Beckn buyer app

Ed25519 + BLAKE2b-512 signing, signed ONDC v2 registry lookups, search through cancel.

Poppy conformant

Official validator over real HTTPS: 99 passed, 0 failed. Direct Sign-In with PKCE.

Conversations and SSE

Cursors, long polling, server-sent events with Last-Event-ID, idempotent message IDs.

Smart baskets

Picks the single seller that covers most of the list and says clearly what is missing.

Zero runtime deps

Node 22.18+ runs TypeScript directly. SQLite via node:sqlite. No build step.

Domain packs

Grocery and food today. Add a vertical with two JSON files, no TypeScript needed.

Security model

The model never holds the keys.

The company-side agent is rule-based on purpose. No language model touches signing keys, session tokens or the approval step.

  • Signed sessions on every requestPoppy-Session JWT bound to aud, htm, htu, ath, replay-protected by jti.
  • SSRF-safe fetchingOutbound URLs are HTTPS-only and private address ranges are refused.
  • Scoped, expiring approvalsOne approval covers one revision in one session, then expires.
  • Bounded storageEvery namespace has a cap. No unbounded growth under load.
